# Security policy

Please report sensitive vulnerabilities privately to the repository owner via
the GitHub repository's available security-reporting channel.

Avoid publishing secrets, detailed personal Wi-Fi identifiers, GPS locations,
or videos of identifiable people in issues.

Droni does not use online accounts, analytics or telemetry uploads. Flight
commands travel over the drone's local Wi-Fi and the legacy protocol does not
provide authenticated, encrypted or acknowledged control packets. Keep the
device within visual range; do not assume the radio link is secure or failsafe.

This project is experimental and not certified for autonomous use.
